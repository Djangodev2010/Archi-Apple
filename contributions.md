## Contribution Workflow

1. Find or Create an Issue: Before starting, check existing issues or open a new one to discuss proposed changes.

2. Write Clean Code: Follow standard PEP 8 styling conventions.

3. Commit Your Changes: Keep commit messages clear and concise.

Sample Commit:
``` bash

git commit -m "feat(docs): created README.md or updated contributions.md rules"
```

Push and Open a PR:

``` bash

git push origin feature/fix/update/your-feature-name
```

Then open a Pull Request (PR) against the main branch.
